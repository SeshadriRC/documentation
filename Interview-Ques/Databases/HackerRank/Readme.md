1. You are given two sets.
Set A = {1,2,3,4,5,6}
Set B = {2,3,4,5,6,7,8}

How many elements are present in A - B?
Only enter the correct integer in the answering box. Do not include any extra spaces, tabs or newlines.

## Solution

`A - B` means **set difference** → elements present in **A but not in B**.

Given:

```text
A = {1,2,3,4,5,6}
B = {2,3,4,5,6,7,8}
```

Remove from **A** all elements that also exist in **B**:

```text
A - B = {1}
```

Number of elements:

```text
1
```

✅ **Answer: 1**
