## 1. Authentication & Connection

```bash
# Log in to Argo CD server via CLI
argocd login argocd.internal.company.com --username admin --password <password>

# Log in using port-forwarding (local development)
# Run in separate terminal: kubectl port-forward svc/argocd-server -n argocd 8080:443
argocd login localhost:8080 --username admin --password <password> --insecure

# Retrieve initial admin password generated during Helm/manifest install
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
echo ""

# Update admin or user password
argocd account update-password

# View client and server versions
argocd version
```

## 2. Application Inspection & Health

```bash
# List all managed applications and their health/sync status
argocd app list

# View detailed status, tree of resources, and git revision of an application
argocd app get my-app

# Inspect application resource tree
argocd app resources my-app

# View live Kubernetes manifests generated by Argo CD from Git
argocd app manifests my-app

# View logs of an application's pods directly through Argo CD CLI
argocd app logs my-app --tail 100 -f
```

## 3. Drift Detection & Synchronization (Syncing)

```bash
# Preview differences between Git desired state and live cluster state (Drift)
argocd app diff my-app

# Manually trigger synchronization of an application
argocd app sync my-app

# Sync a specific resource only (e.g., single deployment)
argocd app sync my-app --resource apps:Deployment:backend-api

# Force synchronization (replaces resources if conflicts exist)
argocd app sync my-app --force

# Synchronize with prune enabled (removes resources deleted from Git)
argocd app sync my-app --prune

# Wait for application to reach Synced and Healthy state (great for CI/CD pipeline steps)
argocd app wait my-app --sync --health --timeout 300
```

## 4. Application Creation & Configuration

```bash
# Create an application using Git repository and Helm/Kustomize path
argocd app create my-microservice \
  --repo https://github.com/my-org/gitops-infra.git \
  --path environments/production \
  --dest-server https://kubernetes.default.svc \
  --dest-namespace production \
  --project default

# Create application with automated sync, self-healing, and pruning enabled
argocd app create my-microservice \
  --repo https://github.com/my-org/gitops-infra.git \
  --path environments/production \
  --dest-server https://kubernetes.default.svc \
  --dest-namespace production \
  --sync-policy automated \
  --auto-prune \
  --self-heal

# Override Helm chart values on the fly
argocd app set my-microservice --values-literal-file ./custom-values.yaml
argocd app set my-microservice --helm-set image.tag="v2.1.0"
```

## 5. History & Rollbacks

```bash
# View deployment and sync history
argocd app history my-app

# Roll back application to a specific history ID (disables auto-sync if enabled)
argocd app rollback my-app 3

# Re-enable automated sync after rollback verification
argocd app set my-app --sync-policy automated --auto-prune --self-heal
```

## 6. Repository & Multi-Cluster Management

```bash
# Add a private Git repository using SSH private key
argocd repo add git@github.com:my-org/gitops-infra.git --ssh-private-key-path ~/.ssh/id_rsa

# Add a private Git repository using HTTPS with Personal Access Token (PAT)
argocd repo add https://github.com/my-org/gitops-infra.git --username git-robot --password <token>

# List configured Git and Helm repositories
argocd repo list

# Add an external Kubernetes cluster to Argo CD (targets current kubectl context)
argocd cluster add <kube-context-name> --name staging-cluster

# List all clusters managed by Argo CD
argocd cluster list
```

## 7. Deletion & Stuck Resource Troubleshooting

```bash
# Delete application and remove all associated Kubernetes resources (Cascade)
argocd app delete my-app --cascade

# Delete application from Argo CD WITHOUT deleting live resources from the cluster
argocd app delete my-app --cascade=false

# Inspect Argo CD Application CRD directly via kubectl
kubectl get applications.argoproj.io -n argocd
kubectl describe applications.argoproj.io my-app -n argocd

# Force remove an Argo CD application stuck in "Terminating" state
kubectl patch application my-app -n argocd --type merge -p '{"metadata":{"finalizers":null}}'
```
